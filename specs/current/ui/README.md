# UI contracts

The UI is a mobile-first Vaadin application presented in Telegram and browsers.

- [Foundations](foundations.md): localization, layout, and shared action affordances.
- [Shared interactions](shared-interactions.md): disclosure lists, scroll cues, temporal controls, and location selection.
- [Navigation](navigation.md): the authenticated shell, home, destinations, and Telegram BackButton.
- [Authentication](authentication.md): login and access-status interactions.
- [Workspaces](workspaces.md): workspace selection and management.
- [Locations](locations.md): saved places, map picking, and proximity suggestions.
- [Participants](participants.md): roster, contact disclosure, and contact actions.
- [Events](events.md): scheduling, publication, and event participant management.

Business rules are owned by [logic contracts](../logic/README.md).
